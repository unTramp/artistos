# 06 Content Factory — Detailed Product Specification

**Status:** REVIEW COMPLETE

Content Factory is the decision-to-execution layer. It does **not** optimize for maximum generation volume. The canonical flow is:

`Context → Angle → Human Review → Execution Package → ContentUnit → Pipeline/Production → Publication → Evidence → Learning`
