# 07 Pipeline / Planning / Calendar

**Status:** Detailed product-spec pass complete.

This domain converts approved creative intent into a realistic operational plan without turning Artist OS into a rigid social scheduler. It owns planning behavior and projections, while canonical content, production and publication state remains in the corresponding domains.

## Features

1. [Content Pipeline](01_pipeline.md) — canonical lifecycle projection, blockers, priority and operational flow.
2. [Content Rhythm Templates](02_content-rhythm.md) — preferred cadence/balance without universal posting quotas.
3. [Evergreen Pool](03_evergreen-pool.md) — meaningful between-release continuity and reusable opportunities.
4. [Recurring Series](04_recurring-series.md) — repeatable formats with identity and fatigue awareness.
5. [Content Slots](05_content-slots.md) — planning windows/intents before exact schedules exist.
6. [Monthly Objective Planning](06_monthly-objective.md) — period focus and trade-offs; product behavior defined, entity boundary still open in MASTER.
7. [Calendar Week/Month](07_calendar.md) — typed temporal projection of slots, shoots, schedules and milestones.
8. [Seasonal Opportunities](08_seasonal-opportunities.md) — market/culture-aware optional planning opportunities.

## Domain invariants

- Planning intent is not execution fact.
- Calendar is not the source of truth for Content/Production/Publication state.
- Cadence is configurable strategy, not universal platform law.
- Flexible capacity and deliberate breaks are valid.
- AI proposes; humans commit schedules and strategic objectives.
- No filler content merely to satisfy a template.
- Bottlenecks and recommendations must be explainable.
- `Monthly Objective` is behaviorally required by MASTER §156 but its formal persisted entity is unresolved and must not be silently invented during implementation.
