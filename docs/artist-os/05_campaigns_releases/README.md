# 05 Campaigns / Releases — Detailed Product Specification

**Status:** REVIEW COMPLETE

This domain defines Campaign as an orchestration boundary and Release as a lifecycle context without absorbing Content, DSP, Distribution, Growth, Business or future Advertising/Publicity bounded contexts.

## Domain invariant

`Campaign coordinates; owning domains own.`

Campaign provides purpose, timing, linkage, attention and review. It must never become the persistence shortcut for every downstream feature.
