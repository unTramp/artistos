# 09 Assets / Media / Rights

**Status:** Detailed product-spec pass complete.

## Domain invariants

- File presence does not imply publishability.
- Credit is not a license.
- Origin, rights and content type are separate dimensions.
- Missing metadata/context stays unknown.
- Smart Ingest suggests; human confirms ambiguous mappings.
- Raw/original assets are preserved; edits create derived lineage.
- Historical evidence and source timestamps are not destructively rewritten.
- Repurposing/atomization optimize useful reuse, not maximum output volume.
- Lineage connects creative decisions to publications/metrics without asserting causation.
